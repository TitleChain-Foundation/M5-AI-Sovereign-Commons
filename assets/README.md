# Visual Assets

![M5 AI Sovereign Commons public review map](commons-overview.svg)

This folder contains the public visuals used to orient readers before they enter
the Commons' standards, technical artifacts, pilots, and evidence. Visuals are
navigation and explanatory aids. They do not override maintained source text,
create authority, or establish implementation, legal, regulatory, or
conformance status.

## Explore this section

| Visual | Purpose | Used by |
| --- | --- | --- |
| [Commons overview](commons-overview.svg) | Maps human authority through open standards, public pilots, and evidence | [Repository home](../README.md) and [documentation map](../docs/README.md) |
| [Section review path](section-review-path.svg) | Shows how each folder connects context, source material, artifacts, and evidence | Standards, schemas, examples, implementations, and test landing pages |

Pilot-specific and review-specific visuals remain beside the material they
explain:

- [People's Trust visual library](../pilots/peoples-trust/README.md)
- [SEC public input review](../sec-public-input/README.md)

## Publication boundary

Only public, reviewed, metadata-safe assets belong here. Private source
material, personal information, credentials, unreleased project identifiers,
and visuals implying unsupported legal or production claims must not be added.
See [Security](../SECURITY.md) and [Contribution requirements](../CONTRIBUTING.md).
