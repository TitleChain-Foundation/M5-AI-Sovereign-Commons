# Pre-Publication Privacy Check

Run on 2026-10-13 and again after adding the sample certificates, before publication, over:

1. the built release package `m5-iam-free-v0.2.0.zip`, unpacked;
2. the evidence generated by the reproducible demonstration;
3. every file added or changed for this release in the repository; and
4. the local test directories used during development (not published).

## What was searched for

- Private key material, GitHub tokens, cloud access keys, provider secrets and
  assigned secrets (the repository's own `tools/check_public_release.py` rules).
- Social Security–shaped numbers and assigned private identifiers (same rules).
- Email addresses and phone numbers.
- Home-directory paths and development-session paths.
- The names of the people and accounts that developed the release.
- Key, certificate and environment files (`*.pem`, `*.key`, `id_*`, `.env*`, `*.p12`).

Matches were reported by rule, file and line only; no matched value was printed.

## Results

| Scope | Result |
| --- | --- |
| Release package | No credentials, keys, emails, phone numbers or local paths. Two name matches, both expected public text: the project name "Norton Ranch Blueprint" in `LICENSE.md` and in `EVIDENCE.md` |
| Reproducible demonstration evidence | No matches. It uses the fixed sample name "Demo Human" |
| Files changed for this release | No credentials, keys, emails, phone numbers or local paths. Name matches are the "Norton Ranch Blueprint" project name only (in `EVIDENCE.md` and in repository paths listed in `MANIFEST.sha256`) |
| Key, certificate or environment files | None |
| Local test directories | One manual test pod held a name and contact details entered during a hands-on trial. It was outside the repository, was never part of the release, and was deleted before publication. The remaining test pods use the sample name "Demo Human" |

The repository's own scan, `python3 tools/check_public_release.py`, also
passes.

## Re-running the check

```bash
python3 tools/check_public_release.py
python3 reference-implementation/m5-iam-free/demo/reproduce.py
```
