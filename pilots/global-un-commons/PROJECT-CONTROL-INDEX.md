## Participant matrix

Participation in Global UN Commons does not imply UN membership, UN
endorsement, diplomatic status, immunity or authority to act for a Member
State. M5-CV holds reusable evidence; project-specific permission is issued
only through a Global
[Project Participation Passport](../../docs/project-control-pack/M5-PROJECT-PARTICIPATION-PASSPORT-AND-ELIGIBILITY-MATRIX.md).

| Role | Pathway | Gate before action |
| --- | --- | --- |
| Public reviewer / researcher | SUPPORT / review | None; review is free and grants no rights |
| Builder / professional | WORK | Credential verification; project selection and engagement |
| Institution / NGO / university / civic organization | SUPPORT / WORK | Verified institutional mandate and scoped agreement |
| Sponsor / underwriter / donor | SUPPORT | Support terms accepted; no ownership, investment, voting or profit right |
| Project member / steward | Governance | Only where a lawful structure provides that role |
| Lender / capital provider | FINANCIAL PARTICIPATION | Instrument classification; eligibility; source-of-funds review |
| Investor | FINANCIAL PARTICIPATION | Only for a separately classified lawful instrument; none exists |
| Host-jurisdiction authority | Authority | Independently verified official mandate |
| Trustee / fiduciary | Regulated / fiduciary | Documented appointment and duties |
| Bank / escrow / custody | Regulated / fiduciary | Regulated institution appointed in the applicable jurisdiction |
| Regulated securities / commodity intermediary | Regulated / fiduciary | Only where actually applicable; registration verified |
| Authorized signatory | Authority | Current, scoped, revocable signing authority |

Opportunities are matched against M5-CV using the
[Work, Opportunity and Support Matching](../../docs/project-control-pack/M5-CV-WORK-OPPORTUNITY-AND-SUPPORT-MATCHING.md)
model. The project remains the decision-maker for engagement, admission and
financial participation.
