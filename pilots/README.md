# Public Pilot Library

![312 Spring Commons concept elevation](312-spring-commons/documents/images/312-spring-commons-concept-elevation.jpg)

This folder is the visual front door to public, inspectable simulations that
test the Commons against concrete scenarios. A pilot turns standards,
authority boundaries, schemas, failure conditions, and evidence requirements
into a sequence that reviewers can challenge before consequential execution.

Public pilots use synthetic or claims-safe material unless a page explicitly
identifies an authoritative public source. A pilot is not proof of a live
transaction, property interest, offering, membership, approval, deployment, or
regulatory status.

## How pilots connect to the Commons

1. [Proposed standards](../standards/README.md) define the control requirements.
2. [Schemas and examples](../schemas/README.md) make proposed records inspectable.
3. A pilot applies those controls to bounded scenarios and failure conditions.
4. [Tests](../tests/README.md), public review, and attributable decisions record
   what passed, failed, changed, or remains unresolved.

New pilots must preserve privacy, separate claims from evidence, and disclose
their exact simulation, proposal, or implementation state.
