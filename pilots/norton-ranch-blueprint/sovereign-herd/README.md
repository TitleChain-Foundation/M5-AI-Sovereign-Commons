# Sovereign Herd

**Status:** Draft public reference implementation — synthetic data only
**Vertical:** M5 Sovereign Agriculture
**Mode:** Local-first / farmer-controlled

## What this pilot tests

## Stewardship, not extraction

Sovereign Herd treats livestock monitoring as a **care system first**. The purpose of sensing and local intelligence is to help the people responsible for animals notice change, preserve continuity of care and make better-informed decisions without converting the animal's life history into a vendor-owned data product.

The animal is not the subscription, and the animal is not merely a data source. The farmer or rancher is the accountable caretaker; technology is there to assist that responsibility.

Sovereign Herd tests whether a farm or ranch can:

- register the accountable human/business relationship;
- create a farm and herd namespace;
- bulk-provision animals;
- register a batch of collars or sensors;
- assign and later replace devices without losing animal history;
- ingest sensor observations locally;
- run behavior/anomaly logic locally;
- keep raw farm data outside the public Commons;
- export the farm's own records in documented formats;
- change hardware/service providers without surrendering the historical record.

## Foundational principle

The public Commons supplies reusable standards, schemas, research references, conformance rules, and reference code.

The farm supplies the private operating history.

Those are not the same data layer.

## v1 boundary

This pilot is passive sensing only.

It does not claim veterinary diagnosis, production certification, animal-control authority, active stimulation, or a live farm deployment.

## Proposed commercial implementation

The M5 implementation may charge one annual farm/business entity activation and optional service charges while avoiding a mandatory M5 per-animal software fee.

The open standard itself remains price-neutral.

## Why this matters

Sovereign Herd is a concrete test of the wider American Producer Innovation Commons. The current market already proves that connected cattle systems can create significant value. The public question is whether American producers and local entrepreneurs should also have a practical path to build and operate compatible systems in which the farm retains control of its underlying data and history.

See the [Halter case study](CASE-STUDY-HALTER-AND-THE-FARMER-OWNED-ALTERNATIVE.md) for the sourced comparison.
