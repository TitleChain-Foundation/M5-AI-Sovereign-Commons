# Public/Open Cattle Data and Software — Starting Research Registry

**Research date:** October 3, 2026

This is a starting evidence registry, not a blanket redistribution license. Source terms must be verified before copying third-party files into a Foundation repository, training package, product image, or commercial distribution.

## 1. Precision Beef — Animal Behaviour Classification

Source: Zenodo record 4064802
DOI: 10.5281/zenodo.4064802

Public record describes approximately 8.2 GB of cattle sensor data covering 18 animals across three farm trials. Animals carried a 3-axis accelerometer sampled at 10 Hz and a second device used for behavioral classifications including eating, rumination, and other.

**Use:** valuable base data for behavior classification research.

**License status in this package:** REVIEW BEFORE REDISTRIBUTION. The public Zenodo page is open-access, but the license field was not sufficiently explicit in the retrieved metadata to treat the full dataset as automatically redistributable.

## 2. University of Strathclyde — Bolus Sensor Acceleration Data With Timestamp and Behavioural Classification

DOI: 10.15129/5e1dfedc-87c7-4af0-bb20-3f3e1388d9d9

The university record describes one CSV containing 107 hours of 3-axis acceleration data with behavior classifications for other, rumination, and eating.

**License:** CC BY 4.0 according to the University of Strathclyde dataset record.

**Use:** suitable for attributed research and model-development workflows subject to the source terms.

## 3. University of Strathclyde — Bolus acceleration data 3x

DOI: 10.15129/fc809102-7288-4b4e-aa48-55ba6608dc2c

Raw bovine bolus acceleration data from three cows.

**License:** CC BY 4.0 according to the University of Strathclyde dataset record.

## 4. BovHEAT

Repository: `bovheat/bovheat`

Bovine Heat Detection and Analysis Tool. The project processes activity-monitoring files and performs estrus/heat analysis.

**Repository license:** MIT as shown on the public GitHub repository page.

**Use:** reference software and methods for fertility/activity workflows. Do not assume rights in input data generated by third-party commercial monitoring systems.

## 5. MmCows

Repository: `neis-lab/mmcows`

Public multimodal dairy cattle research project with wearable-sensor data, UWB/location material, visual data, annotations, and model weights.

**Use:** highly relevant for multimodal and location/behavior research.

**License status in this package:** VERIFY SOURCE-LEVEL TERMS BEFORE REDISTRIBUTION OR COMMERCIAL TRAINING. Code, dataset files, model weights, and imagery may carry different rights or conditions.

## 6. Weather and environmental public sources

Potential public inputs include U.S. government weather/climate and earth-observation sources, plus other open remote-sensing programs. Each connector should preserve:
- source;
- observation time;
- spatial resolution;
- license/terms;
- transformation;
- cache date;
- confidence/quality field.

## Required source states

Every source entry in a production registry should use one of:

- `VERIFIED_PERMISSIVE`
- `VERIFIED_ATTRIBUTION_REQUIRED`
- `RESEARCH_ONLY`
- `NONCOMMERCIAL`
- `REFERENCE_ONLY`
- `LICENSE_UNCLEAR`
- `DO_NOT_REDISTRIBUTE`

No agent should promote a source to a more permissive state without evidence.

## Data separation

Third-party public/open training material belongs in the public source registry.

Farm-generated data belongs in the private farm environment unless the lawful principal explicitly authorizes a transfer or contribution.
