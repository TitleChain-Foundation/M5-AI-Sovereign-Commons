# Simulated GSA/NPS Historic Monument PBC submission

> **SIMULATION — NOT FOR AGENCY RELIANCE OR SUBMISSION.** No eligible applicant, authorization, property availability, agency instruction, approval, funding commitment, title transfer, or closing is represented.

This package demonstrates how the existing Spring Commons materials could be assembled for the working Historic Monument Public Benefit Conveyance pathway under 40 U.S.C. § 550(h). It is a completeness and workflow exercise, not an official GSA or NPS form.

## Evidence states

- `SIMULATION_COMPLETE` — the mock artifact covers its intended workflow and can be reviewed as a simulation.
- `SIMULATION_COMPLETE_WITH_PLACEHOLDERS` — the document is structurally complete but contains fields only an authorized real party can complete.
- `AVAILABLE_DRAFT` — a supporting project document exists but is not executed or approved.
- `PENDING_EXTERNAL` — authoritative evidence, action, selection, signature, or approval is absent.
- `NOT_APPLICABLE_UNTIL_PATH_CONFIRMED` — the requirement depends on GSA's property-specific disposition path.
- `SATISFIED_AUTHORITATIVELY` — reserved for evidence issued or accepted by the responsible external authority; no item in this simulation receives this status.

A check mark in the **simulation** column means only that the repository models the item. It never means the real transaction requirement is satisfied.

## Intended review sequence

1. Confirm the property status and disposition path with GSA.
2. Select and authorize an eligible public applicant.
3. Replace every bracketed placeholder with verified applicant-controlled information.
4. Obtain current property-specific GSA/NPS instructions and conform the package to them.
5. Commission the professional studies and financial evidence listed in the completion matrix.
6. Obtain counsel, governing-body, community, and professional review.
7. Submit only through the eligible public applicant and only after it authorizes the exact package.

## Important process distinction

This package models a restricted public-benefit conveyance, not a competitive purchase. If GSA directs the property to public sale, stop using this package as the transaction submission and follow the property-specific Invitation for Bids or auction terms.

A real-property deed transfer, project financing, and securities transfer-agent function are separate processes. A registered securities transfer agent is included only if the final capital instrument requires one; it does not transfer federal real-property title.
