# Spring Commons Synthetic Example

This folder contains a synthetic JSON example of the Spring Commons
jurisdictional capital-provenance record. It demonstrates structure only and
does not describe a real investor, capital provider, bank account, authority,
transaction, settlement, or project funding event.

## How to review it

1. Read the [DOC-23 human-readable standard](../documents/public/DOC-23-Source-of-Funds-Entity-Provenance-Jurisdiction-Chain-and-Public-Transaction-Graph-Standard.md).
2. Review the [schema guide](../schemas/README.md).
3. Open the [synthetic JSON record](PPT-EZ-CA-0001-jurisdictional-capital-provenance-example.json) only when you are ready to inspect field-level data.
4. Compare the example with the [raw JSON Schema](../schemas/m5-jurisdictional-capital-provenance.schema.json).

The example separates source-chain activation from destination confirmation and
uses privacy-safe placeholders. Do not replace required authoritative evidence
with this sample or reuse its identifiers as production facts.
