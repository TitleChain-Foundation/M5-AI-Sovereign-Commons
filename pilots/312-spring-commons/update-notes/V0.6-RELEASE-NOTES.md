# Spring Commons v0.6 — Release Notes

**Project:** PPT-EZ-CA-0001 / 312 Spring Commons  
**Date:** September 19, 2026  
**Status:** Working draft / public review / counsel review / technical review

## What changed

v0.6 tightens the 23-document Spring Commons package around **open entity grounding, evidence-backed source-chain activation, and privacy-preserving capital-flow intelligence**.

The package now demonstrates a clearer sequence:

`M5BOM / accountable human → role/entity credential → entity grounding → authority verification → source-of-funds evidence → jurisdiction-path resolution → regulatory routing → SOURCE_CHAIN_ACTIVATED → instrument / escrow / settlement events → DESTINATION_CHAIN_CONFIRMED → use-of-proceeds / asset evidence → public and regulator-ready reporting`

## Open-reference graph additions

DOC-23 now recognizes optional, replaceable reference layers including:

- BrightQuery or equivalent for entity/corporate/KYB intelligence;
- OpenCorporates or equivalent for legal-entity registry provenance;
- OpenData.org for an open entity-reference graph and public reproducibility;
- Overture Maps / GERS for open spatial/place grounding;
- official registries, regulators, agencies, professional bodies, banks, courts, and executed instruments as the applicable authority sources.

No external reference source becomes legal authority merely because it is connected to the graph.

## Source-chain activation

A jurisdiction chain is no longer merely a naming convention. v0.6 introduces an explicit evidence state: `SOURCE_CHAIN_ACTIVATED`.

The state is reached only after applicable participant/entity, accountable authority, source-of-funds, intermediary/vehicle, jurisdiction-role, instrument/restriction, conflict/side-arrangement, privacy and regulatory-routing evidence meets the required state.

`DESTINATION_CHAIN_CONFIRMED` remains separate so a verified source path cannot be confused with completed settlement, destination receipt, lawful use of proceeds, title change, or investment performance.

## M5Global intelligence

The research layer may aggregate privacy-protected capital-flow evidence by jurisdiction, project class, instrument, productive-infrastructure category, public/private/philanthropic mix, timing, transaction friction, and other documented dimensions.

Outputs must distinguish:

- OBSERVED
- ESTIMATED
- MODELED
- SCENARIO
- FORECAST

Every derived indicator should carry methodology/version, data snapshot/coverage period, source lineage, confidence/verification state, revision history, privacy threshold/suppression rule, conflicts, and limitations.

## Public opportunity boundary

The M5 Opportunity Registry can show verified project status, procurement/service needs, capital design, and lawful participation pathways. The present M5 Global Index and Exchange concept remains an architecture/discovery concept; the current public intelligence layer is not a securities exchange, ATS, broker-dealer, transfer agent, custodian, clearing agency, bank, investment adviser, or other regulated venue.
