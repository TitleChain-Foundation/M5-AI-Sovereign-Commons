## Reproduce and automate

Run the existing full conformance command in `docs/COMMONS-WEBSITE-SYNC.md`. The repair adds six regression tests in `tests/test_commons_frontend_connections.py`. The existing publication job runs both Commons test modules.

The separate read-only `.github/workflows/commons-frontend-connections.yml` builds the current site/readers and runs the browser audit on PRs, main changes and manual dispatch. It has no Pages write or deployment permission. It installs Playwright 1.56.1 in an isolated runner directory and uploads browser results/screenshots, including failure evidence.

For local browser QA, build a preview using the existing guide, install Playwright 1.56.1 in a separate QA environment, and expose its node_modules through NODE_PATH:

```sh
node scripts/check_commons_search.cjs /absolute/path/to/site-preview /absolute/path/to/browser-evidence
```

With existing Chrome, set M5_CHROME_PATH to its executable. Otherwise install Playwright Chromium in the QA environment. The browser audit checks all 79 indexed search entries, every local detail destination and all 80 project-tab views and 15 core/pathway views at desktop/mobile sizes, labeled filters and filtering, empty results, 17 current calculator links, all three project-design links including the iSWE fragment, all four local quick-entry destinations, local file/fragment targets from every inspected route, execution/HTTP failures, initial-viewport search visibility and search overflow. It does not submit account forms or call protected tools.
