# M5-CV Work, Opportunity & Support Matching

**Status:** Informative architecture\
**Version:** 0.1\
**Date:** September 24, 2026

## Purpose

Use M5-CV to help a person discover and apply for real project opportunities,
not merely display credentials.

The project can publish machine-readable requirements. M5-CV can match verified
skills and current credentials against them.

## Participant front door

A participant should be able to see four separate areas:

### WORK
Find and apply for:
- jobs;
- contracts;
- project assignments;
- professional services;
- apprenticeships;
- operator roles;
- research/build roles; and
- vendor opportunities.

### CONTRIBUTE
Offer:
- time;
- talent;
- public review;
- volunteer work;
- mentoring;
- research;
- standards/testing; and
- community stewardship.

### SUPPORT
Provide, where accepted and lawful:

**Time · Talent · Tokens · Approved cryptographic / sovereign digital currency**

Support paths may include:
- donation;
- grant;
- sponsorship;
- in-kind support;
- restricted project support; and
- approved project contribution rails.

Support is not automatically an investment.

### PARTICIPATE FINANCIALLY
Where a separately classified instrument exists:
- lend;
- invest;
- hedge;
- provide institutional/mission capital; or
- participate through another lawful financial instrument.

Financial participation requires the project/instrument-specific eligibility
and regulatory routing described in the Project Participation Passport and
Financial Instrument Matrix.

## Work matching states

`DISCOVERABLE → MATCHED → APPLIED → UNDER_CONSIDERATION → SELECTED → ENGAGED → AUTHORIZED_TO_WORK`

## Support states

`SUPPORT_PATH_OPEN → SUPPORT_METHOD_SELECTED → REQUIRED_CHECKS → ACCEPTED → AUTHORITATIVE_PAYMENT_RESULT → PROJECT_RECEIPT`

## Investment states

`INSTRUMENT_DISCOVERABLE → POTENTIAL_ELIGIBILITY → VERIFIED_ELIGIBILITY → DISCLOSURES/CONSENT → SUBSCRIPTION/COMMITMENT → ACCEPTED → FUNDED → HOLDER/RIGHT RECORD`

Never collapse these three state machines into one.
