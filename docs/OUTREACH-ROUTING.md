## Common review question

> **What would you need to see, change, or diligence before capital, authority,

## Boundary

Do not route private credentials, personal identity files, account data, private
M5POD records, confidential diligence, proprietary M5Canon internals, keys,
secrets, or non-public deal material through public GitHub channels. Use the
public Commons only for public-safe review, evidence, criticism, and proposals.
