# SHADOW M5Index Methodology — V0.1

**SHADOW = Systemic Holdings, Assets, Debt & Ownership Watch**

SHADOW M5Index makes visible what sits between the public record and the real economy: the state of title, ownership, debt, rights, obligations, capital, transition events, and public-benefit review opportunities.

## Operating principles

- Evidence before inference.
- State before scoring.
- Provenance before automation.
- Authority before action.
- Unknown means unknown.
- Events, not destructive overwrites.
- Rights are separable.
- Obligations travel too.
- Public and private evidence remain separated.

## Index family

- **TSI** — Title State Integrity
- **DSI** — Debt State Integrity
- **ASI** — Asset Stress Index
- **DPI** — Debt Pressure Index
- **OOI** — Ownership Opacity Index
- **CCI** — Capital Concentration Index
- **CCI-DC** — Collection Chain Integrity
- **PVMI** — Public Value Migration Index
- **PBOI** — Public Benefit Opportunity Index

A score does not create legal authority, ownership, transfer rights, or investment rights.

## Initial public sectors

1. Government Buildings & Land
2. Commercial Real Estate
3. Farmland

Sector views may overlap. A government-origin building can also appear in the CRE index; a government-origin agricultural parcel can also appear in Farmland.
