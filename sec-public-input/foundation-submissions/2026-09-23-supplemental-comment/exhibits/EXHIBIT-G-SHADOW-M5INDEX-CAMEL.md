## Existing public artifact

The repository contains **SHADOW CAMEL Report - Q3 2026**, described as a first-edition public-research release using public sources, methodology v0.1, confidence labels, charts, a 36-record asset appendix, and public contribution guidance.

The report's preliminary composite reading is **1.8 / 5 - Band 2 (Stable / Watch), confidence B**. That is the Foundation report's own public-research output. It is not reproduced here as an official or independent assessment.

## Mandatory boundary

SHADOW CAMEL is not:
- an official CAMELS rating;
- confidential supervisory information;
- a bank examination;
- a regulator finding;
- an investment recommendation;
- a credit rating;
- a legal conclusion.

## Public-data pipeline

```text
government/public asset sources
+ county/registry evidence
+ CRE/farmland/public-property datasets
+ debt/maturity/ownership evidence
+ public banking/market data where lawful
-> provenance capture
-> evidence classification
-> source verification
-> asset/right/debt graph
-> SHADOW M5Index research
-> SHADOW CAMEL public-data methodology
-> public challenge/correction
-> versioned superseding edition
```

## Edge participation

The repository already provides issue pathways to nominate a public asset, add registry/public-record evidence, and challenge/correct an index record. A submission enters review; it does not become canonical merely because it was contributed.

Only approved public-safe aggregate events should flow to M5 Global economic-intelligence outputs.
