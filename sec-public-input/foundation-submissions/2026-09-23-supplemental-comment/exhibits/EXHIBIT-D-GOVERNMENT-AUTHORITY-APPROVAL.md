| Question | Required record |
|---|---|
| Who owns/administers the public asset? | authoritative public/title record |
| Which office has disposition authority? | statute/regulation/delegation/agency record |
| Which human may act? | current appointment/role/signature authority |
| In what capacity? | office/entity role and scope |
| Which approvals are prerequisites? | approval matrix with responsible authority |
| Can an agent assist? | explicit bounded delegation |
| What is the controlling instrument? | deed, resolution, contract, approval, permit, etc. |
| What happens if evidence is missing? | HOLD/REJECT |
| What changed after approval? | versioned authority/evidence state |
| What record proves execution? | authoritative system-of-record update + receipt |

## Approval receipt minimum

`who | acting_for_whom | capacity | jurisdiction | authority_source | scope | decision | timestamp | credential_state | evidence | resulting_state | revocation/supersession`
